One funny one-line review a dog gives the mailman, written for the make.fun competition "The Dog Reviews the Mailman".

> Two stars. He comes every day, smells of other dogs, and never once brings the stick. I have filed a formal bark with the fence.

## Why this line

The dog is not angry about the mail — he is angry about the etiquette. A daily visitor who smells of rival dogs and never brings the one thing that matters deserves a formal complaint, filed the only way a dog can: at the fence.

## How it works

`main.py` holds the review in a single string, checks it is within the 1–200 character gate, and writes exactly that line (and nothing else) to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
